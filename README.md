# ai2start

Сайт ai2start.ru — «Наведём порядок в жизни с нейросетями»: каталог услуг с ценами, курс «ИИ для родителей», пакеты, запись в свободные окна и генератор баннеров для ленты, сторис и Telegram.

## Статус

Прототип. Один статичный файл `index.html`, без сборки.

Что пока демо:
- свободные окна и потоки курсов генерируются от текущей даты как пример;
- оплата — заглушка, в рабочей версии здесь будет ЮKassa (карта, СБП);
- форма записи никуда не отправляет данные.

## Стиль

«Карамель»: глянцевый лакированный надутый пластик. Все объекты, слова, плашки и кнопки — сгенерированные картинки в `assets/candy/`. Если файла нет, сайт рисует замену кодом.

## Как поменять

- Услуги, цены, пакеты — массивы `S` и `PACKS` в конце `index.html`.
- Домен на баннерах и в ссылках — константа `SITE`.
- Цвета и шрифты — токены в блоке `:root` в начале стилей.
